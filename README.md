# Bucket List Skills

Agent skills for creating deeply personalized bucket lists — things to do before you die.

## Skills

### `bucket-list-creator`

A coaching-style skill that helps you create your personal bucket list through:

1. **Memory-informed context** — reads your AI memory to understand who you are
2. **Values interview** — a conversational interview about what excites you, what you value, and what scares you
3. **Research** — web search for popular bucket list experiences worldwide
4. **Personalized output** — 50-100 items across 8 categories, each with a "why this fits you" note

**Install:**
```bash
npx skills add aranonet/bucket-list-skills --skill bucket-list-creator
```

**Trigger phrases:**
- "バケットリストを作りたい"
- "死ぬまでにやりたいことリストを作って"
- "bucket list", "life goals", "things to do before I die"

## About

Built by Fumitake Arano. Inspired by ICF coaching methodology and the belief that a truly personal bucket list should reflect your unique values — not a generic top-100 list.
